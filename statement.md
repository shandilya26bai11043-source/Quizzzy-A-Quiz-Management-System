# Project Statement

## Project Title
QUIZZZY - Online Quiz and Performance Analysis System

## Problem Statement
Students need a simple way to practise multiple-choice questions and immediately see how many answers they got right. A paper-based process requires manual checking and does not provide an immediate result. QUIZZZY offers a small console program that records a student's basic details, presents a fixed set of questions, checks the submitted answers, and displays a score and percentage.

## Scope
The project is limited to three major functional modules: Student Login, Quiz Management, and Score Calculation. Student details are stored in a local JSON file. The quiz uses a small sample question set included with the program. The program does not provide an administrator panel, leaderboard, timer, charts, online service, or subject authoring tools.

## Target Users
Beginner students who want to take a short practice quiz, and instructors who want a small example for teaching basic Python program structure.

## High-Level Features
- Register a student with a name, student ID, and password.
- Log in and show the student's basic details.
- Answer four-option multiple-choice questions and move to a previous question.
- Automatically calculate marks and percentage and display the result.

## Technology
Python 3 standard library only; JSON text file for student details.
